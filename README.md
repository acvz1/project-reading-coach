# Project Reading Coach

面向源码阅读、项目学习和协作式编码的 Codex Skill。

它让 AI 不只给出结论，而是围绕真实项目源码维护学习游标，按因果链解释代码，在教学、实现、诊断、规划和笔记整理之间明确切换。

## 解决的问题

- 进入复杂模块后只见局部代码，不清楚整个文件和调用链的职责。
- 变量、泛型、Runtime、Context 等对象反复出现，却不知道从哪里创建、如何传递。
- AI 一次讲太多，或在用户追问时擅自跳到下一个知识点。
- 用户想练核心代码，却把时间消耗在导包、测试、正则和样板逻辑上。
- 验收范围过大，项目的大量时间耗费在重复测试和环境排查。
- 学习笔记只有章节结论，无法在未来还原完整代码逻辑。
- 长周期会话经过上下文压缩后丢失进度、协作规则和源码游标。

## 工作模式

| 模式 | 职责 |
| --- | --- |
| `TEACH` | 基于准确源码位置，一次解释一个必要概念 |
| `IMPLEMENT` | 编写、修改和验证已经授权的代码 |
| `DIAGNOSE` | 定位失败的直接原因，不擅自修改 |
| `PLAN` | 建立项目架构、章节范围、进度和实现路线 |
| `NOTE` | 把已确认知识整理为可复习的因果笔记 |

同一轮只使用一种模式，避免一边讲解、一边改代码、一边扩展需求。

## 核心教学流程

```text
学习者已经接受的事实
  -> 当前源码暴露的具体问题
  -> 现有知识为什么不足
  -> 一个必要的新概念
  -> 最小相关源码
  -> 一个因果结论
```

进入新模块或学习者失去整体结构时，Coach 会先建立模块契约：

```text
模块目标
  -> 类和函数的职责
  -> 当前文件负责与不负责什么
  -> 输入
  -> 调用者
  -> 状态变化
  -> 输出
```

查询变量或类型来源时，则沿着以下链路追踪：

```text
声明或类型别名
  -> 具体构造
  -> 字段填充或修改
  -> 跨层传递
  -> 最终消费者与实际效果
```

## 协作式编码

在让学习者手写代码前，Coach 必须提供：

- 文件或模块的总需求；
- 目标方法的职责与非职责；
- 输入、输出和调用者；
- 可能不熟悉的 API；
- 验收标准；
- 必要的导包和样板准备。

只有位于核心运行链、包含重要业务或设计决策、或者具有明确练习价值的代码才默认交给学习者。测试、导包、适配器、校验辅助函数和重复代码由 AI 承担，除非学习者另有要求。

## 验证与 Git 安全

Coach 使用最小充分验证：

- 优先运行能够证明当前改动的窄范围测试；
- 不重复运行已经通过且没有新增风险的 E2E；
- 区分代码回归、配置缺失、平台差异和无关既有失败；
- 验证异常变慢时及时报告，并提供可直接执行的命令；
- 用户明确跳过非关键验证时，记录未验证边界，不虚报通过。

执行分支、合并、拉取、提交或推送前，必须确认仓库、Worktree、当前分支、upstream、脏状态以及冲突究竟位于本地还是远程。存在无关脏改动时优先使用隔离 Worktree。

## 学习笔记

笔记必须保留：

```text
项目需求
  -> 具体问题
  -> 代码入口
  -> 输入
  -> 关键执行决策
  -> 输出或状态变化
  -> 为什么解决问题
  -> 一个重要边界
```

每条可以独立复习的因果链都需要独立编号和快速索引。章节总结是额外内容，不能代替多个知识点。

## 长周期项目

Coach 会持续维护：

- 当前模式和源码游标；
- 已接受结论与第一个未解决问题；
- 模块契约和完整调用链；
- 学习者与 AI 的代码分工；
- 验证预算和 Git 检查点；
- 笔记检查点、项目计划和被否决方向。

进度按已经承诺的功能单元计算。用户询问进度时，先给百分比，再说明当前单元、剩余关键单元和真实阻塞。

## 快捷控制

| 指令 | 行为 |
| --- | --- |
| `A` | 只回答最新的追问缺口 |
| `C` | 从保存的源码游标继续 |
| `N` | 整理已经确认的学习笔记 |
| `Q` | 发起一次费曼复述检查 |

## 使用

把目录放入 Codex Skills 路径：

```text
~/.codex/skills/project-reading-coach/
```

随后可以直接说：

```text
使用 project-reading-coach 带我阅读这个项目。
先讲清整个模块负责什么，再让我实现核心代码。
从上次保存的源码游标继续。
整理这一章已经确认的学习笔记。
```

也可以显式使用 `$project-reading-coach` 触发。
